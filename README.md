# LaraGram AI SDK

## Introduction

The LaraGram AI SDK provides a unified, expressive API for interacting with AI providers such as OpenAI, Anthropic, Gemini, and more. With the AI SDK, you can build intelligent agents with tools and structured output, generate images, synthesize and transcribe audio, create vector embeddings, and much more.

## Documentation

Documentation for the LaraGram AI SDK can be found on the [LaraGram website](https://laraxgram.github.io/v4/ai-sdk).
